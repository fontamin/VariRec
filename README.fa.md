# VariRec

**VariRec** یک استودیوی انیمیشن فونت متغیر (Variable Font) است که کاملاً داخل
مرورگر اجرا می‌شود. هر فونت متغیری را در آن رها کنید، محورهایش را انیمیت کنید و
خروجی را به‌صورت **GIF**، **MP4** یا **WebM** ذخیره کنید — بدون سرور، بدون
آپلود، بدون نصب.

## چرا VariRec؟

بیشتر ابزارهای فونت متغیر فقط یک پیش‌نمایش ثابت نشان می‌دهند. VariRec برای
«ضبط کردن» ساخته شده است: تمام محورهای فونت شما را به کانال‌های قابل انیمیشن
تبدیل می‌کند و یک انیمیشن آماده‌ی انتشار تحویل می‌دهد. همه‌چیز — از پارس فونت تا
رندر و انکود — به‌صورت محلی در مرورگر شما انجام می‌شود؛ پس فونت‌های شما هرگز
دستگاهتان را ترک نمی‌کنند.

## امکانات

- **بارگذاری فونت متغیر با کشیدن و رها کردن** — فایل‌های TTF، OTF، WOFF و WOFF2
  مستقیماً در مرورگر پارس می‌شوند (جدول‌های `fvar` و `name`)؛ هم محورهای رسمی و
  هم محورهای سفارشی پشتیبانی می‌شوند.
- **دو موتور حرکت**
  - *Sync* — همه‌ی محورهای فعال با هم و روی یک خط‌زمانی مشترک حرکت می‌کنند.
  - *Binary* — محورها مثل شمارنده‌ی دودویی جلو می‌روند (00 → 01 → 10 → 11 …).
- **۸ منحنی ایزینگ** — Linear، Ease In-Out، Ease In، Ease Out، Sine،
  Exponential، Bounce و Elastic.
- **حالت‌های پخش** — Once، Loop و Ping-pong به‌همراه کنترل مدت‌زمان و فریم‌ریت.
- **اورلی اسلایدر محورها** (کاملاً قابل تنظیم و داخل خروجی رندر می‌شود):
  - شکل انگشت (دایره / مربع / گوشه‌گرد / لوزی)، اندازه‌ی انگشت و طول ریل
    (۲۰ تا ۱۰۰ درصد عرض بوم)؛
  - فونت، اندازه‌ی متن، حالت بولد، رنگ اسلایدر و پس‌زمینه‌ی پنل + شفافیت؛
  - برچسب نام و تگ محور، برچسب‌های Min/Max و مقدار زنده با تعداد اعشار ثابت
    (۰ تا ۳ رقم) تا متن وسط‌چین هیچ‌وقت بلرزه؛
  - قطعه‌کد زنده‌ی `font-variation-settings` با مقادیر لحظه‌ای؛
  - قرارگیری بالای/پایین متن، مقیاس پنل و فاصله‌ی «Gap to text» تا ۱۲ em.
- **استایل متن** — اندازه، ارتفاع خط، فاصله‌ی حروف، تراز افقی/عمودی، جهت
  LTR / RTL / خودکار و رنگ متن و پس‌زمینه.
- **کنترل بوم** — پیش‌تنظیم‌ها (16:9، 1:1، 4:3، 9:16، 21:9) یا هر اندازه‌ی
  سفارشی بین ۶۴ تا ۲۵۶۰ پیکسل که با دکمه‌ی تایید اعمال می‌شود تا هنگام تایپ
  چیدمان نپرد.
- **خروجی گرفتن** — GIF (`gifenc`)، MP4 و WebM (با `WebCodecs` و
  `mp4-muxer` / `webm-muxer`) تا ۶۰ فریم بر ثانیه. دکمه‌ی GIF همیشه فریم‌ریت
  *واقعی* را نشان می‌دهد، چون تأخیر فریم‌های GIF روی ۱/۱۰۰ ثانیه گرد می‌شود.
- **رندر مقاوم در برابر FOIT** — هر فریم یک SVG تازه‌سازده است (با فونت embed
  شده به‌صورت data URI) که روی بوم نقاشی می‌شود؛ با settle-poll و ink backstop
  تا گلیف‌ها هیچ‌وقت نامرئی نشوند.

## شروع سریع

```bash
# با Bun
bun install
bun run dev

# یا با npm
npm install
npm run dev
```

سپس <http://localhost:3000> را باز کنید.

فونت متغیر در دسترس ندارید؟ `public/test-vf.ttf` یک فونت نمونه‌ی کوچک با
محورهای `wght` (۱۰۰–۹۰۰) و `wdth` (۲۵–۲۰۰) است که می‌توانید با آن تمرین کنید.

## راهنمای استفاده

1. **فونت را بارگذاری کنید** — یک فایل `.ttf` / `.otf` / `.woff` / `.woff2` را
   روی قسمت بارگذاری بکشید (یا روی آن کلیک کنید). محورهای فونت در پنل سمت راست
   ظاهر می‌شوند.
2. **متن را بنویسید** — از ابزار *Text* در نوار ابزار پیش‌نمایش، یا با کلیک
   مستقیم روی متن داخل بوم.
3. **محورها را انتخاب کنید** — کلید هر محور را روشن کنید تا وارد انیمیشن شود؛
   با اسلایدر مقدار زنده می‌توانید یک محور را روی مقدار ثابت نگه دارید.
4. **حرکت را تنظیم کنید** — حالت *Sync* یا *Binary*، منحنی ایزینگ، حالت پخش
   (Once / Loop / Ping-pong)، مدت‌زمان و فریم‌ریت را انتخاب کنید.
5. **اورلی را استایل بدهید** — ابزار اسلایدرها (آیکن SlidersHorizontal) در نوار
   ابزار پیش‌نمایش را باز کنید تا انگشت‌ها، برچسب‌ها، اعشار، قطعه‌کد CSS، فونت،
   رنگ‌ها، فاصله‌ها و طول ریل را تنظیم کنید.
6. **بوم را دقیق کنید** — اندازه‌ی بوم را با پیش‌تنظیم‌ها یا ورودی اندازه‌ی
   سفارشی عوض کنید (برای اعمال، *Apply size* را بزنید).
7. **خروجی بگیرید** — پنل ضبط را باز کنید و GIF، MP4 یا WebM بگیرید. بعضی
   ترکیب‌ها عمداً فقط برای GIF هستند (Ping-pong و شمارش Binary چندمحوری) — رابط
   کاربری دلیلش را می‌گوید و راه جایگزین را پیشنهاد می‌دهد.

## انتشار روی GitHub Pages

VariRec یک ورک‌فلو آماده دارد:
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). این ورک‌فلو
پروژه را با `next build` (با `output: "export"`) بیلد می‌کند؛ نتیجه یک سایت
کاملاً استاتیک در پوشه‌ی **`out/`** است — همان پوشه‌ای که فایل اصلی
**`index.html`** در آن قرار دارد — و دقیقاً همان پوشه روی GitHub Pages منتشر
می‌شود.

برای آنلاین شدن در **https://fontamin.github.io/VariRec/**:

1. این مخزن را در حساب **`fontamin`** در گیت‌هاب با نام **`VariRec`** پوش کنید
   (`github.com/fontamin/VariRec`).
2. به `main` پوش کنید — یا از تب **Actions** ورک‌فلو را دستی اجرا کنید
   (**Run workflow**). اجرای اول، GitHub Pages را به‌صورت خودکار فعال می‌کند.

ورک‌فلو این کارها را انجام می‌دهد:

1. کد را دریافت و Bun را نصب می‌کند؛
2. GitHub Pages را (اگر هنوز فعال نیست) فعال می‌کند و مسیر پایه (`/VariRec`)
   را از تنظیمات Pages می‌گیرد؛
3. `bun install` و `bun run build` را اجرا می‌کند — سایت استاتیک در `out/`
   ساخته می‌شود؛
4. آرتیفکت پوشه‌ی `out/` (پوشه‌ی حاوی `index.html`) را آپلود و منتشر می‌کند.

سایت شما در این آدرس بالا می‌آید:

```
https://fontamin.github.io/VariRec/
```

مسیر پایه به‌صورت خودکار از نام مخزن گرفته می‌شود؛ پس همین کد به‌صورت محلی
بدون پیشوند و روی GitHub Pages با پیشوند `/VariRec` بیلد می‌شود و نیازی به
تنظیم دستی نیست. اگر روزی نام مخزن عوض شود، آدرس انتشار هم خودکار به‌روز
می‌شود.

## تکنولوژی‌ها

- [Next.js 16](https://nextjs.org) (App Router، خروجی استاتیک) + TypeScript
- Tailwind CSS 4 + shadcn/ui + zustand
- پارسر دست‌ساز OpenType (`fvar`، `name`، WOFF با zlib، WOFF2 با brotli از
  طریق `wawoff2`)
- `gifenc` برای انکود GIF و `mp4-muxer` / `webm-muxer` روی WebCodecs برای
  MP4/WebM

## حریم خصوصی

VariRec صددرصد سمت کلاینت است. فونت‌ها به‌صورت محلی پارس، رندر و انکود
می‌شوند — هیچ‌چیز هرگز به سروری آپلود نمی‌شود.
